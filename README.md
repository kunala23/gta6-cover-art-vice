Vice Cover Maker — a web app that turns a person's photo and a caption into cover art in the style of GTA 6's posters: the multi-panel cover look with bold lettering and a Vice City sunset or neon colour grade, exported as a PNG to share. It runs offline in a desktop browser from its own static files: the photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Load a photo (or the built-in demo photos), pick a layout and a colour grade, edit the caption, and export a PNG in 1080 x 1080, 1080 x 1350 or 1920 x 1080.
